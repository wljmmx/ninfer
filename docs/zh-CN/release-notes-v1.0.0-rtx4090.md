# 发布说明：RTX 4090（sm_89）v1.0.0-rtx4090

本版把此前只在环境变量里存在的**逐出契约**升级为正式启动参数，并把**空闲降级**设为默认开启，
同时补齐 4090 上的 KV 类型与显存策略说明。**默认路径保持逐位不变**（见下"兼容性"）。

## 本版内容

1. **逐出契约成为正式参数**：`--kv-evict off|on|auto` ＋ `--kv-evict-window N`、`--kv-evict-sink N`。
   此前启动顾问一直建议"enable the eviction contract"，但 `src/serve`、`apps` 里没有任何开关能开它
   （只有环境变量），在服务器上这条建议**不可执行**；现在可执行。
   `auto` 由引擎在启动期按四条件判定（容量不足 ∧ 保留比例在实测 <2% 带内 ∧ 主机装得下一次完整抢占 ∧
   该 KV 类型有缺页路径），结论与原因写入启动日志，**不再静默跳过**。
2. **空闲降级默认开启**：`--kv-idle-reclaim-ms N`（默认 `60000`，`0` 关闭）。空闲的共享前缀保留项
   会被降级到主机（字节保留），后续同前缀请求取回复用。实测同一贪心多轮对话在"关/开"两臂
   **生成文本逐字一致**，开臂确实降级 190 页并取回 187 页。
3. **排队超时可到达性告警**：启动时按"竞技场可承载满长车道数 L、期望并发 C、单车道实测预填充速率"
   估算排队最坏等待，超过 `--pending-timeout-ms` 即在启动日志告警（保守上界）。
4. **空闲降级的两处前置修复**：首次共享前缀捕获被误拒；空闲降级在容量压力下不再抢容量路径的活
   （改为让位并单独计数）。
5. **文档更新**：新增中文 KV/显存说明（`docs/zh-CN/kv-cache-and-eviction.md`）；修正 README 中
   "4090 支持 BF16/INT8/FP8/K8V4 KV"的过时表述；补齐 KV 类型表缺失的 `rk4v2-e8`；
   修正 `docs/perplexity.md` 里同样过时的 KV 类型列表。

## 兼容性

- 默认路径逐位不变：门禁 `default PPL 7.441868`、`selector-off dump e7ceb89dff4eb40b`、回归 0。
- `--kv-evict` 默认 `off`；空闲降级的默认值由 0 改为 60000 ms（这是本版**唯一的默认行为变化**，
  且只作用于"空闲的保留项"，已用关/开逐字比对验证输出中性；如需旧行为请传 `--kv-idle-reclaim-ms 0`）。
- 环境变量通道保留且优先级更高，历史实验可复现。

## 已知限制

- `nvfp4` KV 与 NVFP4 权重需要 Blackwell（sm_120a）；RTX 4090 上启动即拒绝，请使用 groupwise-int artifact。
- 无二进制分发：按上游约定从源码构建运行（本仓库只发布源码与说明）。
